# BAC Contracting and Design

Marketing website for BAC Contracting and Design — deck & porch repair,
rebuilds, and restoration serving the Greater St. Louis metro area.

## Structure

- `index.html` — home page (services, reviews, estimate request)
- `work.html` — photo gallery of completed work

Both pages are fully self-contained (images are embedded), so the site is
served as plain static files with no build step.

## Hosting

Served via GitHub Pages from the `main` branch.
